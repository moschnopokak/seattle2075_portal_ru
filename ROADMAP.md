# Дорожная карта портала «Сиэтл 2075»

Составлена по разбору кода (app/, static/index.html, тесты, деплой). Порядок внутри раздела — по убыванию пользы.

## Ближайшее (стабильность)
- Удаление места на карте оставляет «висячие» ссылки в записях, карточках досье и раздатках (`place`, `last_place`). Чистить ссылки при удалении или предупреждать мастера.
- Удаление персонажа из `players.toml` оставляет его в `who`/`answers`/`stars` старых записей. Добавить проверку или команду очистки.
- Браузерные тесты (`test_ui_xss.py`) требуют Chromium: в CI запускать отдельным заданием, локально пропускать, если браузера нет.
- Уведомления Telegram уходят в фоновых потоках без повторов: добавить очередь с повтором и журналом недоставленных.
- `starlette.testclient` с `httpx` помечен устаревшим: перейти на рекомендуемый клиент.

## Средний срок (удобство)
- Кэш `items()`/`entries()`: сейчас каждый запрос читает и разбирает JSON заново. Для десятка игроков хватает, но при росте истории лучше кэшировать по номеру версии.
- Частичное обновление состояния вместо отправки всего `state` после каждого действия.
- Push вместо опроса (`/api/state?since=`): SSE или WebSocket.
- Поиск и фильтры по хронике, досье и записям.
- Экспорт кампании (хроника, досье) в Markdown/PDF для мастера.
- Журнал изменений у мастера: кто и когда правил этапы, досье, раздатки.

## Дальше (развитие)
- Несколько кампаний в одном портале.
- Роли помимо мастера и игрока (наблюдатель, помощник мастера).
- Вложения к записям и обсуждениям (картинки) по тем же правилам, что портреты.
- Календарь: iCal-лента для игроков.
- Автоматические проверки зависимостей и образа (Dependabot уже есть) плюс нагрузочный тест.
