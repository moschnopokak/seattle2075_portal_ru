# Дорожная карта

Черновик на основе разбора кода. Порядок внутри раздела — по убыванию пользы.

## Надёжность
- Один SQLite-коннектор с общим замком: при росте числа игроков вынести чтение в отдельные соединения (WAL это позволяет).
- Запись файла раздатки и записи в `items` идут в разных транзакциях: объединить, чтобы сбой не оставлял «сирот» в `handout_files`.
- Фоновые уведомления без очереди и повторов: добавить короткую очередь с повтором при 429/5xx от Telegram.
- Проверка резервной копии по расписанию (`--verify`) с оповещением мастеру при сбое.

## Безопасность
- Привязка сессии к версии ключа (выход «со всех устройств» без смены `SECRET_KEY`).
- Ограничение частоты запросов на `/api/auth/*` и загрузки файлов (на уровне Caddy/nginx).
- Заголовок CSP для самой страницы портала (сейчас только `frame-ancestors`), после выноса inline-скриптов.

## Функции
- Напоминания игрокам о ближайших записях (за день до).
- Экспорт хроники и досье в Markdown/PDF для архива кампании.
- Поиск по записям, хронике и досье.
- Календарная выгрузка (ICS) личных записей.
- Правка и удаление своих сообщений в обсуждении (с пометкой).

## Качество и разработка
- Разбить `app/logic.py` (900+ строк) на модули: записи, панель мастера, досье/раздатки.
- Разбить `static/index.html` (≈1900 строк) на файлы, добавить линтер для JS.
- Браузерные тесты: запускать в CI на каждый PR (сейчас часть проверок идёт только локально при наличии Chromium).
- Миграции схемы с номером версии вместо флагов `migr:*` в `meta`.
