# Дорожная карта

Составлена по результатам разбора кода (сентябрь 2026). Порядок внутри раздела — по убыванию пользы.

## Ближайшее (надёжность)
- Атомарность загрузки файлов: `handouts.store` / `portraits.store` и `set_items` выполняются отдельными транзакциями. Объединить, чтобы сбой между ними не оставлял файл без карточки.
- Чистка сирот: периодически удалять строки `portraits` / `handout_files` и сообщения без записи.
- Перечитывание `players.toml` не меняет версию данных, и `/api/state?since=` отвечает «без изменений». Поднимать версию при смене файла.
- Проверка целостности ссылок при удалении места: сейчас привязки записей, досье и раздаток просто «пропадают» (интерфейс это показывает); можно чистить сразу.
- UI-тесты (Playwright) в CI: закрепить версию браузера, чтобы не зависеть от окружения.

## Средний срок (возможности)
- Журнал действий мастера (кто и что менял) и откат последней правки.
- Поиск по досье, раздаткам и хронике.
- Напоминания игрокам о неотвеченных приглашениях (раз в сутки, по настройке).
- Экспорт кампании (хроника, досье) в Markdown/PDF для архива.
- Модуль `logic.py` (900+ строк) разбить по разделам: записи, панель мастера, досье и раздатки.
